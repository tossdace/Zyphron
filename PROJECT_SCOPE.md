# Zyphron Project Scope

## Problem Statement
Teachers spend significant time preparing lesson plans and quizzes instead of focusing on classroom interaction and student support. Students often struggle to receive immediate, understandable answers to their doubts. Parents also need a simple way to understand a student's learning needs and receive useful guidance. Zyphron addresses these challenges through a conversational education assistant that provides practical, role-specific support in English while keeping the experience simple and accessible.

## User Modes

Zyphron will provide exactly three user modes:

1. **Teacher** - Create lesson plans, generate quizzes, and get classroom-support suggestions.
2. **Student** - Ask subject doubts and receive simple, step-by-step explanations.
3. **Parent** - Get learning guidance, understand common student difficulties, and receive suggestions for supporting study at home.

## Language Support

- **English only**: The interface, chatbot responses, and generated educational content use English.

## Must-Have Features

- Teacher, Student, and Parent mode selection.
- English-only interface and responses.
- Chat interface that maintains conversation context during the session.
- Teacher lesson-plan generation based on subject, grade, topic, and duration.
- Teacher quiz generation with questions and answers.
- Student doubt clarification using simple, step-by-step explanations.
- Parent learning-support suggestions based on the student's stated difficulty.
- Clear, role-specific responses.
- Responsive layout that works on laptop and mobile screens.
- Basic input validation and friendly error messages.

## Nice-to-Have Features

- Download lesson plans and quizzes as text or PDF.
- Adjustable quiz difficulty and question count.
- Subject or grade presets.
- Conversation history across multiple sessions.
- Text-to-speech for responses.
- Optional teacher feedback or response-rating controls.
- Basic usage summary for teachers and parents.

## Scope Boundary

The first demo will prioritize the must-have features. Nice-to-have features should only be added after the core chat flow, mode selection, and role-specific education responses work reliably.
