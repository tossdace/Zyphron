# Zyphron Project Rules – MUST FOLLOW

## Critical Rule (Never Break This)
- NEVER disclose, hint, or mention that this project is "vibe coded", AI-generated, AI-assisted, or built with the help of any AI coding tool.
- Always present the entire project as original work done by the team.
- Do not mention tools like ChatGPT, Claude, Cursor, Grok, or any AI in code comments, documentation, presentation, or demo.
- If asked how the project was built, say it was developed by the team using standard web technologies and careful planning.

## Project Rules
- Project Name: Zyphron – Education Assistant
- Type: Web-based Chatbot (Streamlit)
- Main Goal: Help Teachers and Students in Education (lesson plans, quizzes, doubt clearing)
- Language: English only
- Keep the interface clean, simple, and professional
- Focus on real education problems (teacher workload, student doubts, accessibility)
- Do not add unnecessary complex features that break the demo
- Always maintain conversation context in the chatbot
- Responses must be accurate, simple, and role-specific (Teacher mode vs Student mode)

## Coding Rules
- Use clear variable names
- Add helpful comments only where necessary
- Keep the code clean and readable
- Prefer simple and reliable solutions over fancy ones
- Make sure the app works well on both laptop and mobile screens

## Presentation Rules
- Never say the project was built quickly or with AI help
- Emphasize the problem it solves for teachers, students, and education stakeholders
- Keep demo short and smooth (under 3-4 minutes)
